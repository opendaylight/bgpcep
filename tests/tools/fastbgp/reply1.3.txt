### Detailed Value and Structural Differences

* **NLRI Framing & TLV Encapsulation:**
* In `draft-ietf-idr-te-lsp-distribution-03`, all parameters were serialized as a continuous, unpadded 21-octet binary string following the NLRI header.


* In RFC 9857, the NLRI body consists of the 1-octet Protocol-ID (`0x09`), the 8-octet Identifier, followed strictly by TLV structures: first the **Local Node Descriptors TLV** (Type 256), followed by the **SR Policy Candidate Path Descriptor TLV** (Type 554).




* **Protocol-ID:**
* Old: Set to `0x07` representing RSVP-TE.


* New: RFC 9857 Section 3 mandates Protocol-ID `9` ("Segment Routing") for all SR Policy Candidate Path advertisements.




* **Local Node Identification (TLV 256):**
* Old: Only carried the raw IPv4 tunnel sender address.


* New: RFC 9857 Section 3 mandates the inclusion of a Local Node Descriptors TLV (Type 256). When the headend originates the path, it MUST include the BGP Router-ID (TLV 516), Autonomous System Number (TLV 512, 4 octets), and at least one local Router-ID (such as IPv4 Router-ID of Local Node, TLV 1028, 4 octets).




* **Path Identification & Stepping Fields:**
* Old: Paths were identified using a 16-bit `Tunnel ID` and a 16-bit `LSP ID`.


* New: In RFC 9857 (aligned with RFC 9256), a candidate path is uniquely identified by the tuple <Headend, Color, Discriminator Endpoint, Originator,>. The `Discriminator` is a 32-bit integer that uniquely differentiates candidate paths from the same originator. In `play.py`, stepping can be mapped directly to `Discriminator` or `Color` instead of `TunnelID` and `LSPID`.




* **Descriptor Length (TLV 554):**
* Old: Fixed payload size of 21 octets.


* New: Type 554 has a variable length depending on IP version flags. For pure IPv4 (`E=0`, `O=0`), the TLV value length is exactly 24 octets.
